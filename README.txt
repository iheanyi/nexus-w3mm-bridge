Keep Vortex running with the Nexus Mods MCP Bridge extension enabled.
Choose your existing W3MM in Settings; Installed mods reads its inventory.
Refresh & check updates checks linked Nexus files. Optional files and variants
are separate choices. Close the game before installing.

Verified main-package updates retire fully replaced old entries without
uninstalling shared files. Keep the bridge's W3MM open between downloads.
Do not uninstall old duplicates in standalone W3MM to tidy its list.

Disable Settings > Use Nexus download buttons to restore Vortex.
Keep this folder in place while the handler is registered.
